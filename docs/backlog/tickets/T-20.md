## Context
The predecessor onboarded through an LLM-driven question flow. Here onboarding is a deterministic, read-only-first detector with evidence for every guess. Read T-06 (config schema, lint, doctor).

## What to build
- `factory init --dry-run`: scan the repo (no writes) for ecosystem markers (`pyproject.toml`, `package.json` scripts, `Makefile` targets, CI workflow files, existing agent instruction files, default branch) and print proposed `verify` argv lists, each with **evidence** (which file/line) and a confidence label.
- `factory init`: write `.factory/project.yaml` from a template (python, node), asking only for what detection could not decide; atomic write; add `.factory/state/` to `.gitignore`; refuse to overwrite an existing project file without `--force`.
- Proposed verify commands must pass T-06 lint and `doctor` on the clean base before `init` finishes (else it prints what failed and writes nothing).
- `factory docs generate`: produce `docs/reference/` (config, events, contracts, policy matrix, lint rules) from schemas and tables; CI fails if the committed output differs (`git diff --exit-code`).

## Demo path
```
$ factory init --dry-run
python/pytest detected (pyproject.toml:[tool.pytest]) -> verify unit: ["pytest","-q"]   confidence: high
$ factory init && factory doctor
```

## Acceptance criteria
- [ ] `--dry-run` leaves the repo byte-identical (tree hash before/after) on three fixture repos (python, node, empty).
- [ ] Each fixture produces the literal expected proposed `verify` argv and evidence string; the empty repo proposes nothing and says so.
- [ ] A detected command that fails on the clean base is reported and `init` writes no file.
- [ ] Existing `.factory/project.yaml` is not overwritten without `--force` (exit 2).
- [ ] `docs generate` is deterministic: running it twice yields identical output; CI step fails when a schema changes without regenerated docs.
- [ ] The written config passes `factory doctor` on each fixture.

## Implementation notes
- Detectors are small named functions returning `(proposal, evidence, confidence)`; adding a language = adding one detector plus fixture.
- Never execute project scripts during detection (read files only); only `doctor` runs commands, and only the lint-approved verify argv.

## Security & failure notes
